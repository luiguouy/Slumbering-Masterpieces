## 1. 规范宗旨与核心原则

本项目《**Slumbering Masterpieces · 沉睡的花园**》致力于为全球观者呈现西方美术史上最璀璨、最广为人知、最具艺术价值的古典传世油画杰作。

为杜绝非著名小众习作、现代抽象概念画、非油画媒介以及带有教学辅助线/水印的残损画作进入展厅，特制定本规范作为**唯一权威的画作遴选、准入审核与数据构建准则**。

### 核心三原则：
- **经典性**：每一幅作品必须是世界艺术史公认的里程碑与名篇，拒绝无名小画与概念草稿。
- **纯粹性**：媒介以油画为主轴（兼顾文艺复兴早期同等地位的蛋彩与湿壁画名作），坚决排除现代立体派、超现实主义、抽象涂鸦与版画。
- **无暇性**：图像必须源自世界顶级博物馆官方高清数字档案，绝不允许任何教学构图线条、几何标记、水印或相框杂质。

## 2. 画作题材分类体系 (四大核心题材)

系统采用**“双维度”**组织架构：
- **主维度（纵向）**：艺术史时期与流派展厅（如文艺复兴、巴洛克、新古典与浪漫主义、写实主义、莫奈专题、印象派、后印象派、表现主义等）；
- **次维度（横向）**：四大核心艺术题材。**每一幅被收录的画作，必须明确归入且仅归入以下四大题材之一**：

### 2.1 🌿 自然与风景画 (Landscape & Nature)
- **题材内涵**：以大自然风光、光影流转、水系海洋、四季更迭、田园与城市风光为核心主体的杰作。
- **典型范例**：
  - 克劳德·莫奈：《日出·印象》、《睡莲池与日本桥》、《干草堆》、《阿让特伊虞美人花田》
  - 文森特·梵高：《星夜》、《罗讷河上的星夜》、《盛开的杏花》
  - 约翰·康斯特勃：《干草车》、J. M. W. 透纳：《雨、蒸汽和速度》
  - 卡斯帕·大卫·弗里德里希：《雾海上的旅人》
  - 卡耶博特：《下雨天的巴黎街道》

### 2.2 👤 人物与肖像画 (Portraiture & Figurative)
- **题材内涵**：以人类个体容貌、神情姿态、贵族平民生活写照、服饰质感与群像为核心表现对象的旷世杰作。
- **典型范例**：
  - 列奥纳多·达·芬奇：《蒙娜丽莎》、《抱银貂的女子》
  - 约翰内斯·维米尔：《戴珍珠耳环的少女》、《倒牛奶的女仆》
  - 扬·凡·艾克：《阿诺菲尼夫妇像》
  - 迭戈·委拉斯凯兹：《宫娥》
  - 让-奥古斯特-多米尼克·安格尔：《泉》、《大宫女》
  - 詹姆斯·惠斯勒：《惠斯勒的母亲》
  - 古斯塔夫·克里姆特：《吻》、《金衣女人》

### 2.3 ⚔️ 历史与叙事故事画 (History & Narrative)
- **题材内涵**：表现人类重大历史转折、革命战役、英雄史诗、民间悲歌、社会风俗与时代叙事的宏大构图巨作。
- **典型范例**：
  - 欧仁·德拉克罗瓦：《自由引导人民》
  - 雅克-路易·达维特：《马拉之死》、《跨越阿尔卑斯山的拿破仑》、《荷拉斯兄弟之誓》
  - 弗朗西斯科·戈雅：《1808年5月3日夜间起义枪杀》
  - 泰奥多尔·席里柯：《梅杜萨之筏》
  - 伦勃朗·凡·莱因：《夜巡》、《杜尔普医生的解剖课》
  - 伊里亚·列宾：《伏尔加河上的纤夫》
  - 让-弗朗索瓦·米勒：《拾穗者》

### 2.4 🏛️ 神话与宗教史诗画 (Mythology & Religion)
- **题材内涵**：以希腊罗马古典神话故事、圣经福音叙事、创世起源、天使圣徒与神圣象征为灵感的殿堂级艺术杰作。
- **典型范例**：
  - 桑德罗·波提切利：《维纳斯的诞生》、《春 · 普里马韦拉》
  - 米开朗基罗：《创世纪 · 创造亚当》
  - 拉斐尔·桑西：《西斯廷圣母》、《雅典学院》、《草地上的圣母》
  - 列奥纳多·达·芬奇：《最后的晚餐》
  - 卡拉瓦乔：《圣马太蒙召》、《朱迪斯斩杀霍洛芬斯》、《酒神巴克斯》
  - 希罗尼穆斯·博斯：《人间乐园》
  - 约翰·威廉·沃特豪斯：《沙洛特女郎》

## 3. “出名油画”三重认证标准 (准入门槛)

任何备选画作必须同时通过以下**“三重认证（Triple Verification）”**，方可进入候选池：

1. **权威通识教材著录（Academic Authority）**：
   - 必须被至少一部世界权威美术史经典教材（如 E. H. 贡布里希《艺术的故事》、加德纳《艺术通史》、詹森《艺术史》）列为重点章节或全页图版深度剖析；
2. **世界顶级博物馆镇馆之作（Museum Distinction）**：
   - 必须是全球顶级博物馆（如法国卢浮宫、奥赛博物馆、纽约大都会艺术博物馆、伦敦国家美术馆、马德里普拉多博物馆、佛罗伦萨乌菲兹美术馆、荷兰阿姆斯特丹国立博物馆等）的核心常设展品或世界公认镇馆代表作；
3. **公众超高认知度与传世名言（Cultural Resonance）**：
   - 作品具有极高的大众辨识度，拥有广为人知的通俗别名或艺术史公认地位；
   - 原作画家针对艺术、自然、光影或生命有可靠记录的经典诗意名言，能与交互展厅的名言系统产生审美共鸣。

## 4. 画作媒介与排除清单 (红线要求)

### 4.1 允许准入媒介
- **布面油画 (Oil on Canvas)**：主选媒介，占比 ≥ 90%；
- **木板油画 (Oil on Panel / Wood)**：如达芬奇、凡·艾克、勃鲁盖尔等早期大师经典之作；
- **同等艺术史地位的文艺复兴早期代表作（特例豁免）**：
  - 蛋彩画 (Tempera)：如波提切利《春》《维纳斯的诞生》；
  - 湿壁画 (Fresco)：如达芬奇《最后的晚餐》、米开朗基罗《创造亚当》、拉斐尔《雅典学院》。

### 4.2 严苛排除清单 (绝对一票否决)
- ❌ **现代抽象/立体派/超现实主义画作**：如毕加索立体派、达利超现实、蒙德里安几何抽象、康定斯基抽象构图、波洛克滴画、安迪·沃霍尔波普艺术等（已由用户明确要求全部删除，不得重新引入）；
- ❌ **版画媒介**：严禁浮世绘木刻版画（如《神奈川冲浪里》）、铜版画、石版画、丝网印刷品；
- ❌ **水彩速写、素描草稿与研究稿**；
- ❌ **非真实历史画作**：严禁任何现代数字合成图（如“莫奈风格合成图”）、AI 生成画作或无名伪作；
- ❌ **不知名小众花卉画**：严禁仅为凑数而收录的大师生平小作、无馆藏编号的次要习作。

## 5. 图像画质与纯净度规范 (防教学辅助线与杂质)

上一轮《自由引导人民》误用教学教材图（带有紫色金字塔三角构图线）提供了深刻教训。此后所有入库图片必须执行以下纯净度红线审查：

| 检查项 | 标准与要求 | 判定违规示例 |
| :--- | :--- | :--- |
| **辅助线条** | **严禁任何几何辅助线**、构图指示箭头、黄金分割线、金字塔三角框、透视消失线 | ❌ 画面上带有紫色、黄色、红色的教学分析几何线 |
| **文字水印** | **严禁任何机构或商业水印**、防盗图标记、网站域名、版权印记 | ❌ 画面角落带有 `Getty Images`、`Shutterstock`、网站网址 |
| **相框装裱** | **仅收录画芯本体（Canvas Image Only）**，严禁外框 | ❌ 图片包含木质浮雕相框、金色画框、博物馆展墙背景 |
| **标签铭牌** | **严禁画作附带展签**、年代解说牌、语音导览二维码 | ❌ 画作右下角拍入了展厅标牌或反光玻璃倒影 |
| **分辨率红线** | **长边像素尺寸 ≥ 2000px**，画面纤毫毕现，无严重 JPG 块状噪点 | ❌ 低于 1200px 模糊低清图、二次有损压缩严重马赛克图 |
| **色彩还原** | **色彩纯正自然**，遵循博物馆馆藏真彩标准校色 | ❌ 被社交媒体滤镜过度饱和化、偏色或严重发黄劣质翻拍 |

## 6. 数据结构与元数据标准 (8大字段)

每幅通过审核的名画在注册至 `masterpieces.js` 时，必须具备以下 8 大标准字段：

```javascript
{
    // 1. 唯一英文字符标识符 (格式: {artist_surname}_{work_key_slug})
    "id": "delacroix_liberty_leading_the_people",

    // 2. 中文标准译名 (含创作年份)
    "title": "自由引导人民 (1830)",

    // 3. 英文或原产国官方题名
    "enTitle": "Liberty Leading the People",

    // 4. 艺术家姓名 (英文 + 中文标准通译)
    "artist": "Eugène Delacroix (德拉克罗瓦)",

    // 5. 所属艺术流派展厅 ID (对应 ART_CATEGORIES)
    "category": "romanticism",

    // 6. 所属四大核心题材标签 ('landscape' | 'portrait' | 'history' | 'mythology')
    "genre": "history",

    // 7. 本地高清图像资产文件名 (存放在 assets/images/ 路径下)
    "file": "delacroix_liberty_leading_the_people.jpg",

    // 8. 经典传世艺术名言与作者署名 (中英双语或经典原句)
    "quote": "“Colour in a picture is like enthusiasm in life.”",
    "quoteAuthor": "— Eugène Delacroix",

    // 9. 资产请求路径 (包含最新缓存控制戳 ?v=X.X.X)
    "src": "assets/images/delacroix_liberty_leading_the_people.jpg?v=3.6.1"
}
```

## 7. 一票否决式入库审查清单 (Acceptance Checklist)

任何新增或替换的名画，在提交合并前必须依次勾选并验证以下 5 个审查关卡：

- [ ] **关卡 1：名气核查（Fame Check）**
  - 该画作是否为全球公认的传世名作？是否在艺术史经典通识教材中作为代表作重点介绍？
- [ ] **关卡 2：题材核查（Genre Check）**
  - 该画作是否清晰属于【自然风景】、【人物肖像】、【历史故事】、【神话宗教】四大题材之一？
- [ ] **关卡 3：媒介核查（Medium Check）**
  - 该画作是否为纯正油画（或同等地位的文艺复兴蛋彩/湿壁画特例）？是否完全排除了版画、水彩、立体派与现代抽象？
- [ ] **关卡 4：图像纯净度核查（Purity Check - 核心防错）**
  - 放大至 100% 仔细检查画面的天空、暗部与边缘：是否存在构图辅助线（如金字塔线条）、教学标记、水印、反光或相框？
- [ ] **关卡 5：技术指标核查（Technical Check）**
  - 图片长边分辨率是否 ≥ 2000px？文件大小适中（通常 800KB ~ 3.5MB 之间）？是否在本地环境中通过 `node -c` 语法检查与渲染实测？

## 8. 权威采信渠道推荐 (Official Sources)

为确保画作版权合法、画质超清且绝无教学辅助线与水印，采信来源按优先级排序如下：

1. **Google Arts & Culture (Google Art Project 权威母带档案)**
   - 官方合作高动态 Gigapixel 扫描，德国爱色丽专业色卡校色，100% Canvas Only。
2. **大都会艺术博物馆开放访问计划 (The Met Open Access API)**
   - `https://collectionapi.metmuseum.org/public/collection/v1/` 官方 4K~8K 公开母带。
3. **芝加哥艺术学院开放数据接口 (Art Institute of Chicago API)**
   - `https://api.artic.edu/api/v1/artworks` 官方 IIIF 超高清直连。
4. **美国国家美术馆与欧洲各大顶级博物馆馆藏母带**
   - 华盛顿 NGA (`nga.gov/open-access-images`)、卢浮宫、乌菲兹、阿姆斯特丹国立博物馆。

## 9. 自动化官方采集引擎 (`scripts/museum_harvester.py`)

为杜绝手动检索引入的低清缩略图、游客实拍照与褪色翻拍，项目已将上述四大世界级官方信源工程化为自动化采集与质检引擎：

- **脚本路径**：[`scripts/museum_harvester.py`](file:///D:/Antigravity_Workspaces/art-web/2026-09-28-secret-garden/scripts/museum_harvester.py)
- **多源优先降级策略**：
  1. `search_google_art_project()`: 优先检索 Google Art Project 官方十亿像素校准档案（过滤掉含 frame, gallery, room 的展厅照片）；
  2. `search_the_met()`: 自动调用纽约大都会官方 `collectionapi.metmuseum.org` 获取 `primaryImage` 高清母本；
  3. `search_artic()`: 自动调用芝加哥艺术学院 IIIF 接口获取 3840px 视网膜母本。
- **自动质量守门员 (QualityGatekeeper)**：
  - 分辨率核验：长边必须 $\ge 1800\text{px}$；
  - 色彩丰富度核验：基于 Hasler & Süsstrunk 算法，得分必须 $\ge 18.0$，平均亮度 $\ge 0.12$（自动拦截死黑与惨白图）；
  - 画面重采样：统一采用 LANCZOS 算法重采样至 Retina 4K 规范（长边 3840px，92% 高品质 JPEG）。
- **命令行调用方式**：
  ```bash
  python scripts/museum_harvester.py "{画名/艺术家}" {保存文件名.jpg}
  ```
